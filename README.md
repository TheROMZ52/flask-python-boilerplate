# NexvorDEV

وب‌سایت رسمی NexvorDEV؛ استودیو توسعه و مهندسی سرورهای بازی.

## Stack

- Next.js App Router
- React
- TypeScript
- Tailwind CSS 4
- Lucide React

## Development

```bash
npm install
npm run dev
```

## Checks

```bash
npm run typecheck
npm run lint
npm run build
```

The public website currently uses static content and does not require a database or external API.
